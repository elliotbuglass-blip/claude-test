# Design changes: ReelBot → Creatr

Every screenshot uses the same test data and screen size (1440 × 900, phone 390 × 844), so each row compares like with like.
They come from the app's saved history, run on a test copy. The live site was not touched.

| Stage | When | What it looked like |
|---|---|---|
| **1. Original** (ReelBot) | up to 19 Oct 2026 | Dark black-and-gold theme, serif headings, menu along the top |
| **2. Light restyle** (Creatr) | 19 Oct 2026 | Renamed Creatr; warm off-white, Satoshi/Inter fonts, white cards, black buttons, new "Let's get creative" home page |
| **3. Now** (Creatr) | 20 Oct 2026 | Every page in one rounded panel tinted from the brand gradient, frosted-glass cards, white text, cream buttons, side rail of icons, Overview dashboard |

## What changed

- **Name:** ReelBot became **Creatr**, with a gradient logo mark.
- **Home page (new):** "Let's get creative". An animated blue → pink → red → orange glow that follows the mouse, and a chat box that answers questions about your reels or turns attached clips into reels.
- **Overview dashboard (new):** reels made this week, views this week, your numbers, research budget, a carousel of your best reels (the panel changes colour with each one), favourites, search, alerts and recent reels.
- **Navigation:** the top menu became a **side rail of icons** with tooltips, the current page in cream, and log out. On phones it becomes a row of icons along the top.
- **Look:** every page sits in a **rounded tinted panel** with **frosted-glass cards** and white text. Each section has its own colour from the same family: Review plum, Upload and Results ocean, Calendar and Clips terracotta, Research amber, Settings slate.
- **Type:** Satoshi headings and Inter text replace the serif headings.
- **Buttons and fields:** cream pill buttons, glass secondary buttons, dark see-through form fields, custom sliders.
- **Readability:** status colours (good, warning, problem) and the source tags (Instagram, TikTok, Trends, Original) were made lighter so they read clearly on the tinted panels.
- **Sign-in page:** a tinted card on the brand glow.
